# Day 02 | Building a Placement Assistant 🤖

## What was Day 2 about?

Day 2 was where I moved from learning the basic concepts of Agentic AI to actually building something with them.

The project for Day 2 was a **Placement Assistant**.

Instead of working with an AI model alone, the project was structured around an assistant that could work with different parts of an application and provide placement-related assistance.

---

## 🛠️ Working on the Project

I worked on the Placement Assistant project locally using Python.

The project had different components for handling things such as:

* Agent logic
* Tools
* Data
* Memory
* Notifications
* Verdicts
* Providers
* Tool dispatching

The project structure helped me understand that an agentic application is not just one Python file. Different responsibilities can be separated into different parts of the application.

---

## 🧠 What I Understood

One of the main things I understood from Day 2 was how the concepts from Day 1 can come together in an actual project.

The assistant has an agent at the center, while other components support what the agent needs to do.

I also got more comfortable looking at an existing project structure and understanding how the different files are connected.

---

## 💻 Building and Running It

I worked with the project locally and tested the application while developing it.

I also worked with the project's virtual environment and used Git while managing the project.

The project was eventually added to my **SoDak Agentic AI Track** GitHub repository as Day 2.
