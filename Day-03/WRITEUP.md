# Day 03 | Exploring Agentic AI with the Agents SDK 🤖

## What was Day 3 about?

Day 3 was about taking the concepts from the previous days further and understanding how an agent can be built using an **Agents SDK**.

After learning the basic building blocks of agents on Day 1 and working with a practical project on Day 2, Day 3 helped me understand how these ideas can be structured using an SDK.

---

## 🧠 What I Learned

### Agents

I learned more about how an AI agent can be defined with instructions and connected to the things it needs to perform a task.

The SDK provides a structured way to work with agents instead of having to manually handle every part of the agent flow.

### Tools

I continued learning about tools and how they allow an agent to perform actions beyond simply generating a response.

The important idea I understood was that tools connect the AI's reasoning with actual application functionality.

### Agent Handoffs

One of the concepts I explored was **handoffs**.

This allows one agent to pass a task to another specialized agent when that agent is better suited for the task.

This introduced me to the idea of having multiple agents with different responsibilities instead of putting everything into one agent.

### Running an Agent

I also learned how an agent can be run through the SDK and how the application receives the agent's result.

This helped me understand how the SDK handles parts of the agent workflow that we explored manually in the earlier days.

---

## 💻 Working Through the Assignment

For Day 3, I worked through the provided assignment and explored the implementation to understand how the different pieces fit together.

Rather than looking at each component separately, I started seeing how agents, tools and handoffs can work together as part of a larger agentic AI application.

---

## 🔍 What Clicked for Me

One thing that became clearer during Day 3 was the difference between **building an agent manually** and using an SDK designed for agent development.

On Day 1, I was introduced to the basic building blocks and agent loop.

Day 2 showed me how those ideas can be used in an actual application.

Day 3 showed me how an SDK can provide a more structured way to build and work with agents.

So my learning progression was:

**Understand → Build → Structure**

---

## 📌 Day 3 Takeaway

Day 3 helped me understand more practical ways of working with agentic AI systems.

The concepts of agents, tools and handoffs gave me a better idea of how multiple components and even multiple agents can work together to complete tasks.

I'm starting to see agentic AI less as just an AI model and more as a system where different components work together.

**Three days in, and the picture is getting much clearer. 🚀**
